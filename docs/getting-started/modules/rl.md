# DiscordLab.RoundLogs

This module will log most things related to the current round, like round start/finish, player cuffed/uncuffed and Chaos/NTF spawn.

## Tracked events:

- Player role changed
- SCP swapping to another SCP (Replaces SCPSwap module)
- Wave respawning (Chaos and NTF)
- Cuffing
- Uncuffing
- Round start
- Round end
- Decontamination begin
