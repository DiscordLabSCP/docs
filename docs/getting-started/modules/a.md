# DiscordLab.Administration

This module is like the higher-up version of `DiscordLab.Moderation`, this allows for administrative things on the server to be logged and done, this module comes with the `/send` command which allows you to send any command to LocalAdmin, hence why this is in this module and not Moderation.

## Tracked events:

- Server start
- Server shutdown
- Client command executed
- Remote admin command executed
