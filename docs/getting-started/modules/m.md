# DiscordLab.Moderation

This module integrated moderation commands and logs into 1 module, this allows your moderation team to be tracked and be able to punish without even needing to join the game.

This module also adds temporary muting functionality, so you can now temporarily mute a player.

**Commands can be disabled via the configuration for this module.**

## Tracked events:

- Muting player
- Unmuting player
- Banning player
- Unbanning player

## Commands (all unspecified types are Discord only):

- `/tempmute` (Remote Admin)
- `/mute`
- `/unmute`
- `/ban`
- `/unban`
